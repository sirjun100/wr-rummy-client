# 反模式与迁移

## 新代码严格遵守 / 迁移批处理可放宽

| 反模式 | 新代码 | 迁移说明 |
|--------|--------|----------|
| `export default class Foo` | `export class Foo` | 旧 subpackage 可暂保留 default |
| `@ts-nocheck` | 去掉并补类型 | 迁移时逐文件清理 |
| `HttpManager.instance` / `static instance` | `GetSystem(NetworkSystem)` | 见 old `merge_network_system` 工具 |
| `PushCenter` / 全局 `EventTarget` | `GameEventSystem` 或类型事件 | |
| Controller 内 `resources.load` | `UIKit` / `ResKit` | |
| 字符串 `RegisterEvent` | 事件 class | |
| 在业务文件复制 `IOCContainer` | 用 `GameApp.Interface` | |
| 修改 `framework/QFramework.ts` 做业务 | 扩展 `game/` | 仅 bugfix/上游同步可改 framework |
| Panel 直接 `GameApp.Interface.GetSystem` 十多处 | 基类 getter 或 Presenter 薄层 | `BasePanel.gameEvents` 模式可保留 |
| `utility/DueWebSocketClient` 等拆文件 | 写在 `NetworkSystem.ts` 底部 `#region Due transport` | 单文件可拷贝迁移 |
| 旧 `ToolUtils` God Class（static 全局状态 + 加载 + 格式化） | 见下表拆分至 `game/utility/*`、Model/System、子包 `RummyCardUtil` | 禁止在新工程新增 `ToolUtils` |
| `AppInfo.shared()` / `window.AppInfo` | `GameApp.Interface.GetSystem(PlatformSystem)` | 兼容期 `OnInit` 仍设 `window.AppInfo = PlatformSystem` |
| 原生桥 / 设备 / 权限 / 三方 SDK | 单文件 [`game/system/PlatformSystem.ts`](../../../assets/script/game/system/PlatformSystem.ts)（`IPlatform` + Web/Android/iOS） | 勿再增 `AppInfo.ts` |

## 错误 vs 正确（片段）

**Singleton Manager**

```typescript
// 错误
export default class HttpManager {
  static instance: HttpManager;
}

// 正确
export class NetworkSystem extends AbstractSystem {
  protected OnInit(): void { /* ... */ }
}
```

**打开 UI**

```typescript
// 错误
resources.load("prefab/Login", Prefab, (e, p) => { /* ... */ });

// 正确
UIKit.OpenPanel(LoginPanel, UILevel.PopUI, null, "lobby", "LoginPanel");
```

**架构事件**

```typescript
// 错误
GameApp.Interface.RegisterEvent("login", () => {});

// 正确
export class LoginSuccessEvent {}
GameApp.Interface.RegisterEvent(LoginSuccessEvent, this.onLogin, this);
```

## 迁移来源

参考 `.old-rummy/wr-rummy-client/`：

- `GameApp.ts` — System 注册列表
- `ui/BasePanel.ts` — UIPanel 扩展
- `system/GameEventSystem.ts` — 频道总线

新工程骨架以 `wr-rummy-client/assets/script/game/` 为准，逐步迁入 subpackage。
