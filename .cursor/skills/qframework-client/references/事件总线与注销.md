# 事件总线与注销

## 两套总线（勿混用语义）

### 1. 架构类型事件（TypeEventSystem）

- API：`GameApp.Interface.SendEvent(LoginSuccessEvent)` 或 `SendEvent(new LoginSuccessEvent(...))`
- 订阅：`RegisterEvent(LoginSuccessEvent, this.onLogin, this)`
- **必须**使用 `class` 作为事件类型；源码 `resolveRegisterEventArgs` 要求第二参数为 handler 函数。

适用：登录成功、钱包变更、架构内模块解耦。

### 2. 频道总线（GameEventSystem）

- 参考：`.old-rummy/.../GameEventSystem.ts`
- `GetSystem(GameEventSystem).emit(channel, payload)`
- `on(channel, handler, target)` 返回 `IUnRegister`

适用：遗留 `PushEvent` 字符串、大量旧 Panel 监听同一 channel。

**规则**：新功能若只需架构内通知 → 用 **事件 class**；仅为兼容旧监听者 → 用 **GameEventSystem** 并在迁移文档登记 channel。

## 注销

```typescript
const unreg = this.RegisterEvent(LoginSuccessEvent, this.onLogin, this);
unreg.UnRegisterWhenGameObjectDestroyed(this.node);
```

或在 `onDestroy` 中 `unreg.UnRegister()`。

`GameEventSystem.offByTarget(this)` 用于按 target 批量清理（迁移代码）。

## OrEvent / EasyEvent

- `EasyEvent` / `EasyEvents`：Toolkit 或局部模块内使用。
- 不要替代 `IArchitecture.RegisterEvent` 做全局业务事件，除非明确是 UI 组件内部。

## 反例

```typescript
// 错误：架构 API 不支持
this.RegisterEvent("LOGIN_OK", this.onLogin, this);

// 正确
this.RegisterEvent(LoginSuccessEvent, this.onLogin, this);
```
